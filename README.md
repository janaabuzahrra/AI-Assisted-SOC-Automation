# AI-Assisted SOC Automation & Incident Response



## Overview
An AI-powered cybersecurity capstone project that uses local Large Language Models (LLMs) to assist SOC analysts in security log analysis, alert triage, threat investigation, incident response, and automated reporting.

The project combines AI with SOAR workflows to simulate the complete incident response process, from threat detection to recovery, with human validation of critical decisions.

## Objectives
- Analyze security logs and investigate suspicious activities.
- Assist in alert classification and false-positive detection.
- Design SOAR playbooks for common cyberattacks.
- Automate selected incident response tasks.
- Generate incident reports and recovery recommendations.
- Evaluate AI accuracy, privacy, and limitations.

## Project Roadmap

**Week 1: Local AI Setup & Prompt Engineering**
- Set up Ollama, LM Studio, or GPT4All.
- Test local LLMs and develop SOC prompts.

**Week 2: Log Analysis & Alert Triage**
- Analyze Windows, Linux, and network logs.
- Generate alert summaries and validate AI findings.

**Week 3: SOAR & Automation**
- Design playbooks for phishing, malware, brute-force attacks, and data exfiltration.
- Define automated actions and human approval requirements.

**Week 4: Incident Response & Reporting**
- Simulate a complete security incident.
- Perform investigation, containment, eradication, and recovery.
- Generate the final incident report.

## Technologies & Tools
- **AI:** Ollama, Llama 3, Mistral, Phi
- **Security:** Windows/Linux logs, SIEM alerts
- **Automation:** SOAR playbooks, TheHive concepts
- **Frameworks:** NIST/SANS Incident Response Lifecycle

## Security & Validation
AI-generated findings will be validated against actual evidence. Critical response actions will require appropriate safeguards and human approval. Testing will take place in an authorized lab environment.

## Expected Outcome
A working prototype demonstrating how AI can support SOC operations through intelligent alert analysis, investigation, controlled automation, and incident reporting.
